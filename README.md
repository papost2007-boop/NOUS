# NOUS - Tutoring Center Management System 🎓

An offline Android management dashboard (CRM) designed specifically for educational and tutoring centers. Built with a focus on speed, usability, and real-world administrative needs.

## 🚀 Key Features
* **Quick Payments:** "One-tap" payment interface designed for fast-paced front-desk environments.
* **Automated PDF Receipts:** Generates professional PDF receipts with business details instantly.
* **Student Management:** Register, edit, and track students effortlessly.
* **Financial Tracking:** Real-time daily cash register and automated monthly debt calculation.
* **Offline First:** Fully local SQLite database ensuring maximum privacy, security, and zero loading times.

## 🛠️ Tech Stack
* **Language:** Java
* **Environment:** Android Studio / Android SDK
* **Database:** SQLite (Local)
* **UI/UX:** Custom "Control Panel" Layout

## 💡 Design Philosophy
The UI was intentionally designed as a color-coded "Control Panel" rather than a standard mobile app. This decision was made to build muscle memory for secretaries and admins, allowing them to perform critical tasks (like processing payments or checking debts) instantly during peak hours without searching through complex menus.
